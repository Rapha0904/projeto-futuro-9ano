# Projeto Futuro — 9º Ano

Experiência interativa para os 9º anos.

## Estrutura

- `index.html` → experiência dos alunos
- `admin/index.html` → painel administrativo

## Firebase

O projeto já está configurado para usar o Firebase definido durante a construção.

O painel administrativo usa autenticação por e-mail/senha.
A experiência do aluno usa autenticação anônima em segundo plano.
